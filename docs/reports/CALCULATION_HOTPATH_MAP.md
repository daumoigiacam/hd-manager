## Important distinctions

- Products x movements is explicit in C10. Requests x products/customers is explicit in C04. Records x records occurs inside C03 per alias group. Delivery candidate indexing limits typical C13, but a dense customer's history can still be expensive.
- Movement product lookup in Nhap Xuat Ton uses `productLookup.get`, not a blanket movements x products scan. Do not assign quadratic complexity to that path without checking its actual helper.
- Main-thread cost and React render cost are different. Pure memo recomputation can be slow before DOM changes; a DOM window can be correct while data work is unbounded.
- The five source-profile observations in the baseline are evidence of hotspots, not exhaustive flamegraph attribution for every action or business correctness certification.

No calculations, regexes, source data, prices, units, stock reset rules or comparison ordering were changed.
